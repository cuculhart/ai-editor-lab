**Overall purpose**

The file implements a lightweight “context builder” for a VS Code‑style IDE.  
It scans a project’s file list, scores files by importance, reads the most relevant ones, splits long files into 2 k‑token chunks, keeps a running token count (capped at 100 k for Gemini 3.8 Flash), and produces a single string that contains the selected file contents and a summary of the token usage. The resulting context can be fed to a language model to give it a concise view of the project.
