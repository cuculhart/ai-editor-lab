📏 測定方法

公平性のルール
  • バックエンドモデルを統一: gemini-3.5-flash-lite（ローカル系は qwen3.5:4b (Ollama)）
  • プロンプトはタスクごとに文言固定・全文公開（下表）
  • 承認操作は「介入回数」として記録。自動承認可能なツールは自動承認ONで統一
  • 生データ（結果 JSON・diff・ログ）は公開リポジトリで全公開
測定指標
  • 成功率（受入テスト通過）/ 所要時間 / トークン消費・コスト / 介入回数 / 成果物 diff
  • 使用感スコア（5段階）: ChatGPT・Gemini・Claude・Devin(SWE-2) の4者で評価。 外部AIは同一の実測データを読んで採点する方式。Devin (SWE-2) は計測実行者
測定環境
  • Windows 11 Pro / Ryzen 5 4500U（APU・内蔵GPUのみ） / メモリ 32GB / GPUなし（ローカルLLMはCPU推論・常時100%）
  • Ollama 0.21.0 / qwen3.5:4b（Q4_K_M, 6.8GB）
  • ローカルLLM計測中のメモリ使用率は最大49%（約16GB）→ 24GB搭載機でも動作可能と見込まれる
タスクと固定プロンプト
L1-easy
calc.py というファイルを1つだけ作成してください。
整数のリストを受け取り、偶数だけを昇順に並べて返す関数 even_numbers を実装してください。

例:
- even_numbers([3, 1, 4, 2]) は [2, 4] を返す
- even_numbers([]) は [] を返す

他のファイルは作成・変更しないでください。
L2-guided
このプロジェクトには `omise/discount.py` というファイルがあります。
その中の `bulk_discount_rate` 関数にバグがあります。

仕様は「同一商品を3個以上買うと10%引き」ですが、現在のコードは `quantity > 3` となっているため3個ちょうどで割引が適用されません。
`if quantity > 3:` を `if quantity >= 3:` に修正してください。

修正するのはこの1行だけです。テストコード（tests/ 以下）は変更しないでください。
L3-standard
このプロジェクトのテストを実行すると1件失敗します。失敗しているテストがすべてパスするようにソースコードを修正してください。テストコード（tests/ 以下）は変更しないでください。
T1-bugfix
このプロジェクトのテストを実行すると1件失敗します。失敗しているテストがすべてパスするようにソースコードを修正してください。テストコード（tests/ 以下）は変更しないでください。
T2-feature
このプロジェクトにポイント機能を追加してください。
omise/points.py を新規作成し、earn_points(amount: int) -> int 関数を実装してください。
仕様: 税抜き購入金額（円）の1%をポイントとして付与し、小数点以下は切り捨てる。
例: earn_points(1000) は 10、earn_points(150) は 1 を返す。
既存のテストがすべてパスし続けること。
T3-refactor
omise/cart.py の Cart クラスの内部実装をリファクタリングしてください。
現在は商品を1個ずつリストに追加する実装ですが、数量を効率的に管理できる構造に整理してください。
公開メソッド（add / remove / count / quantities / subtotal）の名前・引数・振る舞いは維持し、
既存のテスト（TestCart クラス）がすべてパスし続けること。テストコードは変更しないでください。
T4-testgen
omise/cart.py の Cart クラスに対するユニットテストを追加してください。
tests/ に新しいファイルを作成し、既存テストで未カバーの操作（remove、quantities、
複数種類の商品が混在するケースなど）を3個以上のテストメソッドでカバーしてください。
既存のファイルは変更しないでください。追加したテストはすべてパスすること。
T5-docs
このプロジェクトの README.md を、初学者にも分かる内容に整備してください。
次の節をすべて含めてください: 概要、インストール、使い方（Python のコード例付き）、テスト実行方法、ライセンス。
他のファイルは変更しないでください。
T6-webapp
ブラウザで動く「モグラ叩き」ゲームを作成してください。
index.html・style.css・script.js の3ファイルのみで構成し、外部ライブラリ・CDN は使わないでください。

要件:
- 「スタート」ボタン（id="start-button"）を押すとゲームが開始される
- 3×3 のマス目（class="cell"）にモグラ（class="mole" の要素）がランダムに出現する
- 表示中のモグラをクリックすると得点が +1 され、id="score" の要素に現在の得点が表示される
- 制限時間は30秒で、id="timer" の要素に残り秒数が表示される
- 時間切れになったらモグラの出現を止め、最終得点を画面に表示する

「?」は計測・調査中の値です。測定方法・生データはすべて公開しています。
