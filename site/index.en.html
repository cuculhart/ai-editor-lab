AI Editor Lab

This site publishes research results and measured data on AI coding agents — tools that autonomously read files, edit files, and run commands. No spec sheets, no vendor marketing: only results from benchmarks we built and ran ourselves, plus what the numbers actually tell us.

Coverage: 14 agent-style tools (BYOK / local LLM) + 6 Ollama models | Measured: Sep–Oct 2026 | On an ordinary PC — Windows 11, Ryzen 5 4500U, no GPU

This site compares agent-style tools only. We collect tools that can autonomously loop through reading/writing files and running commands. Completion/chat assistants (GitHub Copilot etc.) and major paid subscription tools (Claude Code / Devin / Cursor etc.) are out of scope. Our goal is not to compare models — it is to show that the design of the tool around the model (the harness) is what decides success.

Tokens were arriving but nothing appeared — capping local-LLM CPU threads actually made it feel faster (JA)
Public experiment note | 2026-10 | Difficulty: Intermediate | Japanese

Full-core vs 4-thread CPU allocation in Teaspoon IDE: on Ollama 0.21.0, same generation speed but P95 display lag dropped 181ms→2ms and UI response 929ms→158ms. On 0.40.2 the engine rewrite made the gap vanish — a cross-version tracking record.

Repeated runs with identical model and task surfaced three kinds of "lies": no-op completion claims, implementations contradicting verified facts, and reports contradicting their own results. The differentiator was tool-side harness design, not the model.
