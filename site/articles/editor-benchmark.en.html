A serious comparison of agent-type AI editors only — no subscriptions, running on your own API key

Measured: Sep–Oct 2026 | On an ordinary PC — Windows 11 + Ryzen 5 4500U | Difficulty: Beginner

This site compares agent-type tools only. We collect tools that can autonomously loop through reading/writing files and running commands. Completion/chat assistants (GitHub Copilot etc.) and major paid subscription tools (Claude Code / Devin / Cursor etc.) are out of scope.

🧰 Tools covered (14)

Cline
VS Code extension / Apache-2.0

Arguably the most popular. BYOK & Ollama supported

Roo Code
VS Code extension / Apache-2.0

Development ended and the repo was archived at v3.54.0 (2026-05-15). Successor Roomote is a cloud-agent product, not an IDE tool, so it's out of scope. Community continuation moved to the Zoo Code line. Measurement attempts got no response via either Gemini or Ollama (backend likely down) — recorded as not evaluable

Zoo Code
VS Code extension + CLI / Apache-2.0

Community fork of Roo Code. Runnable via CLI

Kilo Code
VS Code extension / Apache-2.0

Fork in the Roo Code line. Large user base. Local-LLM measurement abandoned — full system freeze (hard power-off) at L1

Continue
VS Code/JetBrains extension / Apache-2.0

Chat-centric, but has an agent mode

OpenHands
Web UI + Docker / MIT

Autonomous agent type. CLI also available

Devika
Web UI (Python) / MIT

Development stalled (last commit 2025-09). Heavy dependencies — install attempt abandoned; recorded as unmeasurable

SWE-agent
CLI (Docker backend) / MIT

Autonomous agent by the SWE-bench team, driven via sweagent run. Requires a Docker sandbox. After the T6 failure, v1.1.0 turned out unable to submit under a standard Windows clone (autocrlf) — further measurement skipped; recorded as not evaluable

OpenCode
Terminal (TUI) / MIT

By SST. Non-interactive runs via opencode run

Aider
CLI / Apache-2.0

The flagship CLI. Easy to automate with --yes

Goose
CLI + desktop / Apache-2.0

OSS agent by Block

Plandex
CLI / MIT

No official Windows build (darwin/linux/freebsd only). WSL required — not measurable on this bench; recorded under installability

Void
VS Code fork / Apache-2.0

OSS Cursor alternative. Standalone editor

Teaspoon IDE
Standalone Electron app / FSL-1.1-MIT

Integrated Explorer/Monaco/Git/TTY. Formerly Forger
