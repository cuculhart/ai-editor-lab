計測: 2026年9月〜2026年10月 ｜ Windows 11 + Ryzen 5 4500U の一般的なPCで実測

このサイトの比較対象は「エージェント型」だけです。 ファイルの読み書き・コマンド実行まで自律で回るツールのみを集めています。 補完・チャット補助型（GitHub Copilot 等）や、月額サブスクの大手有料ツール （Claude Code / Devin / Cursor 等）は対象外です。

🧰 対象ツール一覧（14 本）

Cline
VS Code 拡張 / Apache-2.0

人気最大級。BYOK・Ollama 対応

Roo Code
VS Code 拡張 / Apache-2.0

v3.54.0 で開発終了・リポアーカイブ済み（2026-05-15）。後継 Roomote はクラウドエージェント製品でIDEツールではないため対象外。コミュニティ継続は Zoo Code 系へ。計測試行は Gemini・Ollama 両経路で無応答（バックエンド停止の可能性）→ 評価不能として記録

Zoo Code
VS Code 拡張 + CLI / Apache-2.0

Roo Code のコミュニティフォーク。CLI 実行可

Kilo Code
VS Code 拡張 / Apache-2.0

Roo Code 系フォーク。ユーザー数大 LocalLLM計測はL1で全システムフリーズ(強制電源断)により断念

Continue
VS Code/JetBrains 拡張 / Apache-2.0

チャット型だがエージェントモードあり

OpenHands
Web UI + Docker / MIT

自律エージェント型。CLI もあり

Devika
Web UI（Python） / MIT

最終コミット 2025-09 で開発停滞。依存が重く導入試行を断念 — 計測不可として記録

SWE-agent
CLI（Docker バックエンド） / MIT

SWE-bench チーム製の自律エージェント。sweagent run で駆動。Docker サンドボックス前提。T6 失敗後、現バージョン(v1.1.0)は Windows 標準 clone(autocrlf) で submit 不能と判明し以降の計測を見送り — 評価不能として記録

OpenCode
ターミナル（TUI） / MIT

SST 製。opencode run で非対話実行可

Aider
CLI / Apache-2.0

CLI の代表格。--yes で自動化しやすい

Goose
CLI + デスクトップ / Apache-2.0

Block 製 OSS エージェント

Plandex
CLI / MIT

公式に Windows ビルドなし（darwin/linux/freebsd のみ）。WSL 必須のため本ベンチでは計測不可 — 導入可否の記録対象

Void
VS Code フォーク / Apache-2.0

OSS の Cursor 代替。独立エディタ

Teaspoon IDE
独立 Electron アプリ / FSL-1.1-MIT

エクスプローラー/Monaco/Git/TTY一体型。旧称 Forger
