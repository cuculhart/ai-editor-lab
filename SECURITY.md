# Security Policy

This repository contains the AI Editor Lab benchmark data and the static
site published at <https://labo.mond.jp/>.

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

- Preferred: use GitHub's [private vulnerability reporting](https://github.com/cuculhart/ai-editor-lab/security/advisories/new)
- Alternative: email <contact@cuculhart.com>

We aim to acknowledge reports within a few days.
